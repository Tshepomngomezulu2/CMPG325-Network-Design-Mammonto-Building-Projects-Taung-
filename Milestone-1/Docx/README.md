# CMPG 325 — Mammonto Building Projects Network

This repository contains the network design and implementation project for Mammonto Building Projects (Taung), developed for CMPG 325 — Computer Networks.

The project includes the initial network requirements, physical and logical topology, IP addressing plan, Cisco Packet Tracer implementation, testing evidence, troubleshooting, and final project documentation.

**Client:** Mammonto Building Projects (Taung)
**Addressing Block:** 10.32.0.0/16
